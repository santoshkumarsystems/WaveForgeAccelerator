# cuWaves Dataset Contract

WaveForge Accelerator trains its neural network **from scratch in PyTorch** using a deterministic dataset generated by the independent **cuWaves C++ physical simulation project**.

The training code does not reimplement the wave equation and does not begin from a downloaded pretrained model.

The data lineage is intentionally explicit:

```text
cuWaves C++ physical simulation
        ↓
deterministic dataset generation
        ↓
10,000 wave examples
        ↓
64 spatial field samples per example
        ↓
AI model training from scratch in PyTorch
        ↓
trained amplitude + wavelength predictor
```

---

## Dataset location

The generated CSV is expected at:

```text
data/raw/cuwaves_wave_dataset.csv
```

The dataset is regenerable and is intentionally excluded from Git.

---

## Physical source

The current dataset is generated from the 1D wave form used by cuWaves:

$$
F(x,t) = A \sin(kx - \omega t + \phi)
$$

$$
k = \frac{2\pi}{\lambda}
$$

where:

- $A$ = amplitude
- $x$ = spatial position
- $t$ = time
- $k$ = wave number
- $\omega$ = angular frequency
- $\phi$ = phase
- $\lambda$ = wavelength

For the underlying wave equations, numerical implementation, and CPU/CUDA validation, see the independent **[cuWaves project](https://github.com/santoshkumarsystems/cuwaves)**.

For the current dataset:

```text
time       = 0
phase      = 0
frequency  = 1 Hz
x_start    = 0
dx         = 0.05 m
samples    = 64 spatial positions
```

The spatial grid is therefore fixed across examples while amplitude and wavelength vary.

## Learning problem

The neural network consumes:

```text
[x0, x1, ..., x63]
```

and predicts:

```text
[amplitude, wavelength]
```

So the supervised inverse problem is:

```text
64 spatial field values
        ↓
AI model trained from scratch
        ↓
amplitude + wavelength
```

---

## Why amplitude and wavelength are the targets

Amplitude is directly represented by the magnitude of the spatial waveform.

Wavelength is represented by the spacing of the spatial oscillation.

For a single spatial snapshot at fixed time, temporal frequency is **not independently identifiable** unless additional temporal samples or another physical relationship are introduced.

That is why the current model predicts:

```text
amplitude
wavelength
```

rather than:

```text
amplitude
frequency
```

Although the dataset records `frequency = 1 Hz` as provenance, frequency is fixed and is not a learned target in the current experiment.

## Training relationship

The dataset feeds the PyTorch `WaveRegressor`:

```text
64 inputs
  ↓
Linear 64 → 32
  ↓
ReLU
  ↓
Linear 32 → 16
  ↓
ReLU
  ↓
Linear 16 → 2
  ↓
denormalization
  ↓
amplitude + wavelength
```

The network is initialized and **trained from scratch** using this cuWaves-generated dataset.

## Why cuWaves remains independent

Dependency direction is intentionally one-way:

```text
cuWaves
   ↓
WaveForge Accelerator
```

cuWaves remains an independent numerical/physics project.

WaveForge Accelerator consumes its generated physical data for AI training, compiler experiments, and runtime validation.

This prevents the accelerator project from embedding a duplicate wave simulator inside the training code.

---

## Reproducibility principle

The source of truth is:

```text
cuWaves generator configuration
+
deterministic seed
+
training code
```

not a manually edited CSV.

The raw dataset can therefore be regenerated rather than committed to the repository.
